# 🎨 Spot Painting Project

A Python-based **Spot Painting** project created using the `turtle` graphics library. The program generates a colorful dot painting using a custom RGB color palette, with **Colorgram** explored for extracting colors from an image.

---

## 📌 Project Overview

This project uses Python's **Turtle Graphics** to create a visually appealing spot painting inspired by modern dot-art and pointillism.

The program uses a predefined RGB color palette to randomly select colors for each dot. The project also includes an explored implementation using the **`colorgram.py` package**, which can extract dominant colors from an image and convert them into RGB values suitable for Turtle graphics.

The Colorgram extraction code is currently commented out, as the final version uses a predefined color palette.

## 🔧 How It Works

The program follows this workflow:

1. A custom list of RGB colors is created.
2. Turtle's color mode is configured for RGB values.
3. The turtle is configured for fast drawing.
4. A function randomly selects a color.
5. The turtle draws a colored dot.
6. Movement functions control the turtle's direction.
7. A cycle function combines movement and dot drawing.
8. A loop repeats the cycle to create the painting.
9. The Turtle window remains open until the user clicks on it.

### Colorgram Workflow

The project also explores an alternative method:

```text
Reference Image
      ↓
Colorgram Extraction
      ↓
Dominant Colors
      ↓
RGB Values
      ↓
Color Palette
      ↓
Turtle Dot Painting
```
